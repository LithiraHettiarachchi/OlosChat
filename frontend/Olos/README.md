# Olos Project Structure

This folder contains the three separate applications for the Olos system:

1.  **landing** (`frontend/Olos/landing`)
    *   The public marketing website.
    *   Runs on **Port 3000**.
    *   Command: `npm run dev`

2.  **dashboard** (`frontend/Olos/dashboard`)
    *   The Admin Dashboard.
    *   Runs on **Port 3001**.
    *   Command: `npm run dev`

3.  **chatspace** (`frontend/Olos/chatspace`)
    *   The Chat Workspace.
    *   Runs on **Port 3002**.
    *   Command: `npm run dev`

## Getting Started

To run the entire system, you will need to open 3 separate terminals and run `npm run dev` in each respective folder.
